\title{Porting a continuous-energy Monte Carlo to CUDA in pure Rust:\\[0.3em]
\normalsize What we built, what it weighs, and what we
believed that wasn't true}
\author{F\'abio Rodrigues\\\small \texttt{sorcerer86pt@gmail.com}}
\date{2026}

\maketitle

\begin{abstract}
This paper documents the CUDA port of \texttt{open\_rust\_mc},
a pure-Rust continuous-energy neutron / photon Monte Carlo
transport code with recursive-CSG geometry, SVD-compressed
cross sections, and an ICSBEP regression substrate. The CPU
and GPU backends share a single \texttt{EigenvalueRunner}
trait so benchmarks run through either path with the same
scene JSON, nuclear data, and acceptance envelope.

We describe the engineering pieces that survived contact with
realistic workloads: a process-wide per-nuclide device-buffer
cache and a parallel S($\alpha$,$\beta$) buffer cache, both
keyed on \texttt{Arc::as\_ptr}; runtime detection of the
device's compute capability so one binary targets RTX A1000
through Blackwell RTX 5090 without rebuilds; a refill-pool
auto-recommender for the event-batched pipeline; and a
\texttt{-{}-debug-metrics} observability path that snapshots
cache and device state per case. We report measurements
across saturation, refill, and cache-hit regimes on RTX A1000
and RTX 3080.

\end{abstract}
